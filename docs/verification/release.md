## MP4 chapter-carrier compatibility rebuild (current)

The supplied 512,743,677-byte MP4 has one `data/bin_data` chapter carrier, MP4 track ID `0x3`, sample-entry tag `text`, language `eng`, and handler `SubtitleHandler`. Its five chapter titles and bounds span 0–1564 seconds. The previous cover writer rejected all data streams. The fix reads `moov/trak/tkhd/tref/chap`, matches the referenced `tkhd.track_ID` to FFprobe's stream `id`, and skips only that positively identified carrier's explicit `-map`; `-map_chapters 0` recreates it. Any absent, ambiguous, malformed, unreferenced, or differently tagged data stream remains unsupported. The parser is bounded to 10,000 boxes and 64 IDs per `chap` payload, reads at most a 24-byte `tkhd` prefix plus each box header/reference list, and skips `mdat` by offset.

- The current Windows 10 host is not a clean second-machine test. Windows 11, a second machine, and a clean-machine install are **unverified**.
- The local Shell thumbnail API returned the expected embedded-cover colors, but an Explorer window was not visually checked. Explorer rendering remains **unverified**.
- Actual plugin registration/enable/disable was intentionally not run because it changes the host `.mp4` handler. The main installer leaves registration off by default; registration and takeover behavior was tested only under the isolated Pester registry root. The standalone scripts remain available for an explicit user opt-in.
- The installer is unsigned. No publisher certificate/signing configuration was available in this workspace.
- C1 wording describes RGB as an image-wide average. For C2, the first emitted frame at requested time 0.5 seconds has PTS 0.5; the later `showinfo` 0.6 entry was buffered and was not an output frame.
- No debug-report exporter exists, so no new export feature was added.
- This workspace has no Git repository; no Git initialization or commits were made.
