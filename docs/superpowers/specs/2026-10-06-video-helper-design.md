# 视频助手第一版设计

日期：2026-10-06

状态：用户已确认完整设计，进入实现计划阶段。尚未进入实现。

## 1. 目标与平台

开发 Windows 10/11 x64 本地桌面工具，采用 Electron + React，使用 FFmpeg/FFprobe 处理视频。提供两个核心功能：

1. 从在线 m3u8 链接或本地 m3u8 文件获取已结束的完整视频，校验分片并合并为单个视频文件。
2. 按视频时间点选择画面，将该画面作为封面嵌入视频，优先兼容未安装本工具的 Windows 文件管理器。

封面应随视频文件复制、移动和改名，不依赖本工具数据库或外部图片路径。未安装工具的电脑是否显示指定封面，由该电脑的缩略图处理器决定，不能承诺全部原生生效。原生方式无法生效时，提供可选的 Windows 缩略图插件。

第一版不录制直播，不做完整播放器，不生成候选截图，不提供外部图片导入，不提供逐帧定位。

## 2. 页面与操作流程

左侧导航提供「下载任务」「设置封面」。设置页用于临时目录、下载并发和可选插件管理。

### 2.1 下载任务页

顶部切换「在线链接 / 本地文件」。在线模式输入 HTTP/HTTPS m3u8 URL；本地模式选择或拖入 m3u8，并可填写基础 URL。

点击「解析」后显示：

- 可用清晰度；只有一条媒体列表时不要求用户选择。
- 可用音轨；没有独立音轨时不展示音轨选择。
- 播放列表声明的总时长、分片数量。
- 保存目录、输出名称；下载前允许编辑。
- 本地模式下的资源解析示例，便于检查基础 URL。

确认信息后创建任务。任务列表显示阶段、进度、下载速度和错误原因，并提供暂停、继续、取消、重试、打开输出目录和设置封面的入口。

### 2.2 设置封面页

可从已完成的任务进入，也可选择或拖入本地视频。

页面包含：

- 静态画面预览。
- 覆盖视频总时长的时间轴。
- 时间输入框，格式为 HH:mm:ss.SSS。
- 前后微调时间按钮，第一版每次调整 0.1 秒。这是时间调整，不承诺恰好移动一帧。
- 「设为封面」按钮、最终封面预览和保存区域。

拖动时间轴时立即更新时间文本，松手后提取画面；编辑时间后按回车或结束编辑时提取。若连续发起请求，只展示最后一次请求对应的画面，避免旧结果覆盖新时间点。

初始预览取视频内的有效画面；时间限制在可解码的有效范围内，视频结束边界不提取不存在的帧。输入异常时就地提示，不发起提取。

「设为封面」从原视频提取该时间点对应的有效帧，保持原始画面比例，不拉伸。时间轴标记与提取结果一致；时间输入精度不代表原视频存在毫秒级帧。

第一版没有播放、声音、自动播放、候选图列表和逐帧按钮。画面提取由 FFmpeg 完成，不依赖 Chromium 能否播放该视频编码。

## 3. m3u8 输入与资源定位

### 3.1 在线播放列表

使用播放列表实际响应 URL（包含重定向后的地址）解析相对资源；子播放列表使用自己的响应 URL 作为基准。支持主播放列表和媒体播放列表。

### 3.2 本地播放列表

资源定位规则：

1. 资源本身为完整 HTTP/HTTPS URL：直接使用。
2. 用户填写基础 URL：相对 URI 按标准 URL 解析规则解析到该基础 URL。
3. 用户未填写基础 URL：相对文件路径相对于当前本地播放列表所在目录解析。

基础 URL 用于本地列表内的子播放列表、媒体分片、密钥和初始化分片；下载到的远程子播放列表以其自身实际响应 URL 为基准。

界面说明目录型基础 URL 应包含末尾斜杠。例如 `https://example.com/videos/` 与 `parts/001.ts` 解析为 `https://example.com/videos/parts/001.ts`。不自动猜测或继承签名查询参数。

支持「本地 m3u8 + 本地分片」以及「本地 m3u8 + 网络分片」。本地输入文件和原始分片不因任务清理被删除；清理仅针对工具创建的临时副本。

## 4. 下载、校验与合并

### 4.1 范围与检查

第一版目标为已结束的 HLS 点播列表。检查选中媒体列表的结束标记；缺少结束标记时提示可能不完整，第一版不直接创建完整视频下载任务。

按 HLS 描述处理资源，不能把所有分片假设为 TS。第一版处理普通 TS、fMP4 初始化分片、字节范围、独立音轨及常见 AES-128 分片加密；不支持的加密方式和异常播放列表在开始前明确报错。

合并由 FFmpeg 读取保留必要 HLS 信息的本地播放列表完成，不通过按文件名排序或直接拼接二进制替代 HLS 处理。

### 4.2 下载策略

默认每任务最多 4 个网络请求并发，第一版同一时间执行一个下载任务，其余排队。下载失败自动重试最多 3 次，使用递增等待；权限、链接过期和不支持的格式不持续盲目重试。

分片先写临时文件，传输成功及可用长度检查完成后才记为完成。网络资源在服务端没有声明长度时，不以缺少 Content-Length 判定失败；后续由解复用和合并验证完整性。

保存播放列表快照、资源清单、已完成分片和任务状态，用于暂停恢复及应用重启后继续。第一版按完整分片恢复，不承诺从单个分片内部的某字节继续。

暂停停止调度新资源，并终止正在传输的资源；未完成资源不计入完成数。取消终止任务并保留记录及临时文件供用户恢复或清理。清理为单独明确操作。

恢复时核对缓存资源和所选播放列表。如果远程列表或资源已变化，阻止混合旧、新分片并提示重新创建任务。链接过期时给出原因，第一版不自动刷新站点登录或签名。

### 4.3 合并与输出

全部必要资源齐备后，进入合并阶段。优先复制原始音视频编码并输出 MP4。

若编码与 MP4 不兼容，用户可选择保留编码输出 MKV，或转码为 H.264/AAC MP4。转码属于独立选择，不自动发生。

使用临时输出路径，完成后检查文件可解析、选中音视频流存在且时长与播放列表在合理容差内一致。通过后才发布最终文件。验证失败保留中间资源并显示原因，避免把不完整文件标记为成功。

成功后默认清理工具创建的分片缓存，可选择保留。磁盘不足、路径不可写、同名文件、FFmpeg 进程失败均提供明确错误；不静默覆盖已有文件。

## 5. 封面保存与兼容性

### 5.1 保存方式

第一版封面写入优先支持 MP4。MKV 可以选时间点和导出图片，但不在第一版承诺其封面写入或原生缩略图兼容性；需要封面写入时可另行选择输出 MP4。

默认另存为 `视频名_封面.mp4`，保留原视频。用户也可明确选择「替换原文件」。替换操作先完成临时文件生成和验证，再进行可恢复的替换；失败保留原文件。

能复制编码时不重新编码原音视频。封面是内嵌图片，不作为视频开头片段，不改变正常播放内容。封面保存失败时不输出伪成功提示。

同时提供单独导出 JPG 封面的操作。导出图片不是文件管理器缩略图生效的前提。

### 5.2 优先进行技术验证

正式铺开界面和封面模块前，先用小样片验证内嵌封面的具体写入方式：

- 在未安装本工具插件的 Windows 10/11 默认缩略图环境中检查结果。
- 用新文件路径与刷新后的缓存检查，避免把旧缩略图误判为当前封面。
- 确认常用播放器可以正常播放，原音视频流与预期一致。
- 复制文件到另一台干净测试环境，检查封面携带与显示。
- 更换一次封面，检查缓存更新与图片读取。

实际结果必须记录 Windows 版本、视频格式/编码、封面写入方式、缩略图处理器和测试现象。开发机上的成功不能推断所有电脑均成功。

「封面已写入」可由程序验证。只有实际检查了文件管理器显示效果后，才可记录「本机文件管理器已确认显示」；不把工具自己的图片预览当作系统显示验证。

若默认 Windows 环境不支持所验证的内嵌封面方式，报告实测边界并保留可携带的内嵌封面设计，通过可选插件满足显示需求。不能为达成原生兼容而偷偷修改视频播放画面。

### 5.3 可选缩略图插件

提供 Windows 原生 `IThumbnailProvider` 扩展，读取视频内嵌封面。插件在工具关闭后仍可被文件管理器调用。

默认安装主工具不注册插件。用户选择启用后才执行安装与注册，并提供独立插件安装包，供其他电脑只安装缩略图功能。

注册前检查原有缩略图处理器，保留恢复信息；未设置内嵌封面的文件仍需提供正常的视频取帧缩略图，不使其他视频失去预览。卸载时只在当前注册仍属于本插件的情况下恢复原处理器，避免覆盖后来安装的插件。

插件优先读取内嵌封面，不查询 Electron 数据库、不启动 Electron、不在缩略图请求中联网。考虑进程隔离、错误回退、缓存刷新和 x64 注册。

安装插件的环境仍需保证文件管理器已开启缩略图显示，且视频与封面格式处于已验证的支持范围。

## 6. 模块边界

- React 界面：输入、解析结果、任务状态、时间轴与静态预览。
- Electron 主进程：文件选择、进程调度、持久化、受控 IPC 和输出管理。
- HLS 解析与资源定位：输出明确资源清单、清晰度、音轨和时长，不负责界面。
- 下载器：并发调度、重试、暂停与资源缓存，不负责封面。
- 视频处理服务：封装 FFmpeg/FFprobe 的合并、探测、时间点取帧和封面写入。
- 任务存储：保存任务及恢复所需状态；第一版使用本地结构化任务文件和独立缓存目录。
- 原生缩略图插件：独立构建、安装和验证；只服务文件管理器缩略图请求。

界面不直接拼接 shell 命令。FFmpeg 参数以参数数组传递，路径和 URL 作为数据处理。敏感 URL 不无条件写入可分享的错误报告。

## 7. 任务状态与错误体验

任务状态为：排队、下载中、已暂停、合并中、已完成、失败、已取消。解析发生在任务创建前，封面处理是独立操作。

下载进度区分资源下载和合并，不能在尚未验证合并结果时显示任务完成。缺少资源、基础 URL 错误、网络失败、链接过期、分片损坏、磁盘不足及封面格式不支持均说明原因及可执行的下一步。

封面提取和保存期间显示忙碌状态，允许正常查看其他任务，不阻塞整个界面。应用退出时终止子进程并保存可恢复状态。

## 8. 验收与实现顺序

1. 先验证 MP4 内嵌封面在干净 Windows 环境中的表现，以及时间点静态取帧是否可用。
2. 实现 HLS 解析、资源定位、下载与合并核心，用固定样例验证在线和本地输入。
3. 完成下载界面、进度、重试、暂停和恢复。
4. 完成时间轴、时间输入、静态预览和封面保存。
5. 完成可选原生插件、独立安装包、恢复原处理器及兼容性验证。
6. 打包主工具，实测安装包和安装后占用。

关键验收包括：相对路径解析、带基础 URL 的本地列表、本地分片不被误删、主列表选择、独立音轨、fMP4/字节范围、AES-128、缺失分片、网络中断恢复、取消、不完整列表拒绝、输出可播放、封面另存/替换失败保留原文件、快速调整时间不显示旧画面，以及插件安装/卸载不破坏原有处理器。

安装包先以约 200 MB 为优化目标，前期按 150～250 MB 的精简构建估算；采用完整 FFmpeg 或增加依赖时可能更大。该数值不是验收保证，最终以实际构建为准。下载视频与临时分片的空间单独计算。
